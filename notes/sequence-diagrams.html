Authorization — RBAC + Ownership (IDOR blocked)

Role check passes, but the ownership check stops vendorA reading vendorB's settlement.

Client (vendorA)
API
DB
GET /settlements/s2
authorize("settlement:view-own") ✓ role ok
fetch s2
s2 { vendorId: vendorB }
ownership: s2.vendorId ≠ vendorA ✗
403 — not your settlement 🔒
Two gates: the role allows the action; the ownership check confines you to your own rows. Skipping the second = IDOR (change the ID in the URL → see another vendor's money).
